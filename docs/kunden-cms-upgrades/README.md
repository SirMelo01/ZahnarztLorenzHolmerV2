# Kunden-CMS-Upgrades

Dieser Ordner sammelt wiederverwendbare Anweisungen und kundenspezifische Protokolle fuer Upgrades alter kundenangepasster YooLink-CMS-Projekte.

## Dateien

- [vorlage.md](vorlage.md): allgemeine Master-Vorlage fuer zukuenftige Kunden-Upgrades
- [knn-truckclaim.md](knn-truckclaim.md): konkrete Upgrade-Anweisung und Protokoll fuer KNN TruckClaim
- [zahnarzt-lorenz-holmer.md](zahnarzt-lorenz-holmer.md): konkrete Upgrade-Anweisung und Protokoll fuer Zahnarzt Lorenz Holmer

## Verwendung

1. Fuer neue Kundenprojekte `vorlage.md` kopieren.
2. Platzhalter durch Kunden- und Projektnamen ersetzen.
3. Scope, zu entfernende Funktionen, Frontend-Seiten, Datenmigration und Deployment-Ziel konkretisieren.
4. Die kundenspezifische Datei als verbindliches Arbeitsprotokoll im jeweiligen Upgrade verwenden.
